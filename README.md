A comprehensive Python-based system for managing and analyzing student academic performance. 
This project demonstrates fundamental Python programming concepts including data structures, 
control flow, functions, and interactive menu systems.

## Project Objectives
This project implements a complete student management system that can:
- Store and manage student academic records
- Process and validate student data
- Calculate grades and analyze performance
- Check graduation eligibility
- Provide interactive menu-based navigation
- Perform advanced data analysis with nested structures

## Features

### Part 1: Data Collection and Storage
- Variable declarations with proper data types (string, int, float, boolean)
- List of student names
- Dictionary-based student profiles with nested data
- Set for unique courses
- Tuple for fixed department information

### Part 2: Data Processing and Logic
- Grade calculation using IF/ELIF/ELSE statements
- Feedback system using MATCH/CASE
- Input validation with TRY/EXCEPT error handling
- Type conversion (string to int/float)
- Age and CGPA validation

### Part 3: Analysis and Reporting
- List slicing operations (top 3, last 5, every other, reverse)
- Set operations (intersection, union, difference, symmetric difference)
- Performance analysis (average CGPA, high performers)
- Outstanding courses tracking

### Part 4: Interactive Menu System
- Console-based menu using MATCH/CASE
- View all students
- Add new student with validation
- Check graduation eligibility (CGPA >= 2.5, no outstanding courses, active status)
- Find top performer by CGPA
- Logical operators (AND, OR) for complex conditions

### Part 5: Advanced Challenges (Optional)
- Nested data processing with course scores
- Average score calculation for each student
- Identification of students scoring above 70 in ALL courses
- Pattern matching with type detection (int, float, str, list, dict, tuple, set, bool)
- Interactive type checker

## How to Run

### Prerequisites
- Python 3.x installed on your system
- A code editor (VS Code recommended)

### Running the Program
1. Clone this repository or download the files
2. Navigate to the project directory
3. Run the program:
```bash
   python student_analysis.py
```
   or
```bash
   python3 student_analysis.py
```

### Using the Menu System
When the program runs, you'll see an interactive menu with options:
1. View all students - Display list of all registered students
2. Add new student - Add a new student record with validation
3. Check eligibility for graduation - Verify if a student meets graduation requirements
4. Find top performer - Display the student with the highest CGPA
5. Process nested student scores - Analyze detailed course scores
6. Type detection demo - See automatic data type detection
7. Interactive type checker - Test type detection with your own inputs
8. Exit - Close the program
